# BLASTp Analysis of SpCas9

## Objective
To evaluate the sequence similarity of SpCas9
against protein sequences available in the NCBI
non-redundant protein database.

## Query Information
- Protein: SpCas9
- Organism: Streptococcus pyogenes
- UniProt accession: Q99ZW2
- Sequence length: 1368 amino acids
- Tool: NCBI BLASTp
- Database: NCBI nr

## Results
- Non-empty BLAST hits analysed: 51
- Average percentage identity: 99.874%
- Maximum percentage identity: 100%
- Average query coverage: 99.971%
- Maximum bit score: 2792
- Displayed E-value: 0.0

## Interpretation
The selected database matches showed very high
sequence similarity to the SpCas9 query.

Thirty hits showed 100% query coverage, while
21 showed approximately 99.93% coverage.

Five hits showed 100% sequence identity.

The results include PDB structural records and
RefSeq protein records. Therefore, the 51 hits
should not be considered 51 independent natural
homologues.
